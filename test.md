## League Classic

### Systems

**Melee Minions**

* Base HP: 430 -> 440

**Caster Minions**

* Base HP: 270 -> 280
* Base AD: 22.0 -> 22.5

### Champions

**Amumu**

* Q Mana Cost: 50 -> 80/90/100/110/120
* R no longer knocks down enemies

**Blitzcrank**

* W no longer self-slows

**Katarina**

* Selected Version: Release -> ~V3.12
* Differences from V3.12:
  * W AD Ratio: 50% bonus AD -> 60% bonus AD
  * R Damage: 400/575/750 (+375% bonus AD) (+250% AP) -> 480/690/900 (450% bonus AD) (+300% AP)

**Lulu**

* E no longer deals 2224.5 (+5% AP) at level 15.

**Skarner**

* R Cast Range: 500 units -> 350 units
* R additionally has improved targeting.

**Sona**

* Spells are no longer toggles.

**Twitch**

* Selected Version: Release -> ~V3.10

**Warwick**

* W Range: 20000 units -> 1200 units
* W AS Duration: 6 seconds -> 10 seconds

### Items

**Health Potion**

* Max Stacks: 5 -> 99
